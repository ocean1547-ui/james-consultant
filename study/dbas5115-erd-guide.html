DBAS 5115 Assignment 1 — ERD Code & Guide

이 문서는 Acme Medical Clinic 데이터베이스의 ERD(Entity-Relationship Diagram)를 자동으로 생성하기 위한 코드와 사용 설명서입니다. 아래 코드를 복사하여 dbdiagram.io에 붙여넣기만 하면 완벽한 ERD가 생성됩니다.

1. ERD 생성 방법 (1분 완성 가이드)

  1. 단계 1: 인터넷 창을 열고 무료 ERD 생성 사이트인 dbdiagram.io 에 접속한 뒤 "Go to App" 버튼을 누릅니다.
  2. 단계 2: 화면 왼쪽에 적혀있는 기본 예제 코드를 모두 지우고, 이 문서 아래에 있는 "ERD 생성 코드"를 그대로 복사하여 붙여넣습니다.
  3. 단계 3: 코드를 붙여넣는 순간 화면 오른쪽에 8개의 테이블(Department, Employee, Patient, Service, Appointment, Appointment_Service, Invoice, Payment)과 그 연결선(1:N, M:N, 재귀적 관계)이 완벽하게 그려진 다이어그램이 나타납니다.
  4. 단계 4: 화면 상단의 "Export" 버튼(또는 그림 위에 마우스 우클릭)을 눌러 그림을 PNG 파일이나 PDF로 저장합니다. 이후 비디오 녹화 시 이 그림을 띄워놓고 발표(Section 1 스크립트)를 진행하시면 됩니다.

2. ERD 생성 코드 (dbdiagram.io 전용 DBML)

아래 박스 안의 코드를 처음부터 끝까지 전부 복사하세요.

Table department {
  dept_id integer [primary key]
  dept_name varchar
  location varchar
}

Table employee {
  emp_id integer [primary key]
  first_name varchar
  last_name varchar
  role varchar
  email varchar
  phone varchar
  hire_date date
  salary numeric
  dept_id integer
  supervisor_id integer
}

Table patient {
  patient_id integer [primary key]
  first_name varchar
  last_name varchar
  dob date
  gender varchar
  blood_type varchar
  phone varchar
  email varchar
  address varchar
  emergency_contact varchar
}

Table service {
  service_id integer [primary key]
  service_name varchar
  cost numeric
}

Table appointment {
  appt_id integer [primary key]
  patient_id integer
  emp_id integer
  appt_date timestamp
  status varchar
  reason text
}

Table appointment_service {
  appt_id integer [primary key]
  service_id integer [primary key]
  quantity integer
}

Table invoice {
  invoice_id integer [primary key]
  appt_id integer
  total_amount numeric
  issue_date date
}

Table payment {
  payment_id integer [primary key]
  invoice_id integer
  amount_paid numeric
  payment_date date
}

Ref: employee.dept_id > department.dept_id
Ref: employee.supervisor_id > employee.emp_id
Ref: appointment.patient_id > patient.patient_id
Ref: appointment.emp_id > employee.emp_id
Ref: appointment_service.appt_id > appointment.appt_id
Ref: appointment_service.service_id > service.service_id
Ref: invoice.appt_id - appointment.appt_id
Ref: payment.invoice_id > invoice.invoice_id
